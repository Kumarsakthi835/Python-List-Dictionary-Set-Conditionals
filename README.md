# 🐍 Python Data Structures: List, Dictionary, Set & Conditional Statements

## 📌 Project Overview

This assignment focuses on working with core Python data structures such as

## 🔍 Key Concepts Used

| Concept | Description |
|---------|-------------|
| **List Creation** | Created lists with integers and strings |
| **append()** | Added item to end of list |
| **insert()** | Inserted item at specific index |
| **remove()** | Removed specific item from list |
| **pop()** | Removed and returned last item |
| **extend()** | Added multiple items to list |
| **sort()** | Sorted list in descending order |
| **max(), min(), sum()** | Analyzed list values |
| **Dictionary** | Created key-value pairs |
| **keys()** | Retrieved all dictionary keys |
| **values()** | Retrieved all dictionary values |
| **items()** | Retrieved all key-value pairs |
| **Set** | Unique unordered collection |
| **Union** | Combined all elements from both sets |
| **Intersection** | Common elements from both sets |
| **if, elif, else** | Conditional decision making |

---

## 💡 Key Insights

- Sets automatically remove duplicate values
- Sets do not support indexing — TypeError occurs
- Dictionary values are accessed by key not index
- List methods directly update the original list
- Union combines all elements, Intersection finds common elements
